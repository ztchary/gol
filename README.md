# gol

Blazingly fast Conway's game of life simulator

---

Uses a glorious hashmap implementation and some bitwise magic to compute the next frame instantly.

GPU acceleration would be tuff as well.


### Keybinds

- q to quit
- s to step one generation
- p to pause and play simulation
- c to show 8x8 chunks
- right click and drag to move and scroll to zoom
- left click to draw cells
